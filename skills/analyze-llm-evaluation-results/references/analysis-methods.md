## 数据合同

计算前建立字段表：

| 内容 | 必须确认 |
|---|---|
| 行粒度 | 一次执行、唯一样本、标注记录还是聚合行 |
| 唯一键 | case ID、run ID、版本和重复序号如何组合 |
| 状态 | pass、fail、skip、error、unknown 的业务含义 |
| 分数 | 范围、方向、单位、缺失含义、权重和阈值 |
| 分组 | 模型、Prompt、参数、系统、维度、场景和语言 |
| 对照关系 | control、experiment 以及唯一变化变量 |
| 评分来源 | 人工、规则、自动指标或 Judge |
| 版本 | 模型、Prompt、数据、工具、评分器和执行日期 |

不要把空字符串、`0`、`N/A`、`unknown` 或工具错误擅自解释成失败。先确认。

## 格式读取

- **CSV/TSV**：检查编码、分隔符、引号、换行、多行文本和列数漂移。
- **Excel**：确认文件、工作表、隐藏行列、公式与缓存值、合并单元格和日期格式。多个工作表不要默认拼接。
- **JSON**：确认顶层对象、记录数组路径、嵌套字段和数值/字符串类型。
- **JSONL**：逐行验证 JSON，保留错误行号；不要因一行损坏静默丢弃整批数据。
- **日志**：先定义事件边界、请求/追踪 ID、时区、重试和多行堆栈，再转成记录。
- **人工标注**：确认标注员、轮次、盲评方式、仲裁结果和量表版本。

只在本地使用已获准的解析工具。Excel 脚本依赖缺失时先告知用户，不自动上传到在线转换服务。

## 数据质量

### 完整性

报告文件数、行数、有效记录数、唯一样本数、各版本样本数和跨版本可配对样本数。

### 重复

区分：

1. 完全相同的重复行；
2. 同一唯一键重复；
3. 设计要求的重复采样；
4. 重试产生的多条执行；
5. 同一测试在不同版本下的合法配对。

删除前先确认保留规则，例如首条、末条、成功条或全部运行聚合。

### 缺失

按字段和关键分组报告缺失数量与比例。识别：

- 真正缺失；
- 不适用；
- 未执行；
- 执行错误；
- 解析失败；
- 被权限或脱敏策略移除。

版本间缺失率不同本身可能造成结果偏差。

### 异常与一致性

检查：

- 分数越界、非法状态和不可能组合；
- 时间倒序、重复时间戳和时区混用；
- 同一标签的大小写、空格和别名；
- 同一 ID 对应不同输入或参考答案；
- 测试过程中 Prompt、知识库、工具或评分器版本漂移；
- 只保留成功请求造成的幸存者偏差；
- 测试集进入训练、Prompt 示例或调参过程造成的污染。

## 指标口径

### 比率

`通过率 = 通过数 / 可判定样本数`

必须单独报告 skip、error、unknown 和缺失。除非合同明确，不把它们放入分母或直接算作失败。

比例同时报告 Wilson 置信区间。小样本即使通过率为 100%，下界也可能很低。

### 平均方式

- **微平均**：按所有样本汇总，容易被大维度主导。
- **宏平均**：先算每个维度再平均，让小维度权重相同。
- **加权平均**：使用明确业务权重；必须展示权重来源。

至少同时给出各维度样本数，避免平均值掩盖覆盖差异。

### 连续分数

报告均值、中位数、标准差、四分位数、最小值和最大值。重尾或有界分数优先使用分位数和 bootstrap 区间。

### 严重程度

同时报告数量和失败占比。高严重度的单个新失败可能比大量低严重度改善更重要。

## 版本比较

先确认实验只改变一个目标变量。若模型、Prompt 和知识库同时变化，只能把结果归于“整体方案变化”。

同时报告：

- control 与 experiment 的 `n`；
- 绝对差值，例如 `+3.2` 个百分点；
- 相对变化，例如相对基线 `+5.0%`；
- 置信区间与效应大小；
- 配对改善、配对退化和无变化；
- 各维度及严重度变化。

同一 case ID 配对的二元结果可使用 McNemar 检验；独立比例使用两比例方法；连续配对分数使用配对检验或 bootstrap。选择方法前检查独立性、分布和样本量。

多次比较会增加偶然“显著”结果，需控制 FDR/家族错误率或明确探索性分析。

结论措辞：

- 区间和业务阈值都支持：可靠提升/退化；
- 方向一致但区间跨过无差异：方向性变化，证据不足；
- 样本过少或组间不可比：无法可靠判断；
- 未显著：未观察到可靠差异，不等于完全相同。

## 评分一致性

### 分类与有序评分

- 报告完全一致率和混淆矩阵；
- 名义分类使用 Cohen's kappa；
- 有序量表使用加权 kappa；
- 多标注员可考虑 Fleiss' kappa 或 Krippendorff's alpha。

### 连续评分

同时查看：

- 平均绝对误差；
- 平均偏差；
- 相关系数；
- 分数段偏差；
- 一致性图或 Bland–Altman 思路。

相关性高不代表绝对一致。

### Judge

按 Judge 版本、Prompt、候选顺序、答案长度、维度和严重程度切片。检查位置偏差、自偏好、冗长度偏差和版本漂移。使用人工校准集并抽检 P0/P1 和争议样本。

## 统计限制

- 置信区间反映抽样不确定性，不自动覆盖数据偏差、标签错误和系统漂移。
- 非独立重复运行不能当成同等数量的独立样本。
- 只测试固定黄金集可能高估泛化能力。
- 极少失败时，失败率估计和聚类都不稳定。
- 观察性数据只能支持关联和假设，因果结论需要随机、配对或单变量隔离实验。
