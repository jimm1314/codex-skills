## 失败分析层级

按顺序记录：

1. **可观察症状**：最终答案错、无引用、工具未调用、超时等；
2. **故障发生点**：最早出现异常的系统层；
3. **传播路径**：异常如何影响后续输出与评分；
4. **根因候选**：可能导致故障的因素；
5. **确认状态**：已确认、数据支持的推断或待验证猜测；
6. **验证动作**：需要的日志、重放、对照实验或人工复核。

只有最终输出时，通常只能确认症状，不能确认内部根因。

## 归因分类

| 类别 | 常见症状 | 所需证据 | 隔离方法 |
|---|---|---|---|
| 模型能力问题 | 推理、知识、指令遵循或稳定性不足 | 固定上下文的多次原始输出 | 固定其他变量更换模型或重复执行 |
| Prompt 设计问题 | 漏约束、冲突、歧义或示例诱导 | 最终组装 Prompt 与优先级 | 只修改一项 Prompt 后重放 |
| RAG 检索问题 | 目标证据未召回或排序过低 | 查询改写、候选、分数、过滤和上下文 | 直接注入正确证据，对比生成结果 |
| 上下文截断 | 关键指令或证据未进入模型输入 | Token 计数、截断位置、最终上下文 | 缩短或调整排序后重放 |
| 工具选择错误 | 未调用、错选或多余调用 | 可用工具定义、选择轨迹 | 固定任务和工具集做对照 |
| 参数生成错误 | 字段缺失、类型、单位或实体错误 | 工具 Schema 与实际参数 | 直接使用正确参数调用工具 |
| 工具执行失败 | 工具超时、权限或业务错误 | 原始请求、响应、错误码和重试 | 绕过模型直接重放请求 |
| 工作流编排问题 | 顺序、状态、循环、重试或停止错误 | 节点轨迹、状态快照和路由决策 | 逐节点重放或绕过编排层 |
| 系统接口问题 | 序列化、缓存、网络或版本契约错误 | 服务日志、追踪 ID 和接口载荷 | 对接口录制回放并比对 |
| 测试数据问题 | 参考错误、标签错、覆盖偏或数据污染 | 数据来源、版本、标注历史 | 盲法人工复核和新样本对照 |
| 评分规则问题 | Rubric 含糊、阈值错或实现不一致 | 规则版本、分项分数和判定代码 | 用已知锚点样本复算 |
| LLM Judge 偏差 | 位置、长度、自偏好或版本漂移 | Judge Prompt、顺序、版本和人工标注 | 交换顺序、换 Judge、盲法人审 |

一次失败可以有多个传播因素，但应指定一个主要症状和当前最早证据点。

## 聚类与代表案例

### 聚类

先使用结构化字段聚合，再考虑文本聚类：

1. 按已有失败类型、维度、场景、版本和严重度统计；
2. 对未分类文本提取不含敏感内容的症状摘要；
3. 形成候选主题并人工命名；
4. 检查大簇是否混合多个根因、小簇是否只是措辞差异；
5. 保留“未知/证据不足”，不要强迫所有失败进入已知分类。

聚类频率不等于根因频率：一个上游故障可能制造多个下游症状。

### 代表案例

分层选择：

- 高频簇的中心案例；
- 每个高严重度类别；
- 新版本新增回归；
- 人工与自动评分冲突；
- 聚类边界或置信度最低案例；
- 明显改善及仍未修复的对照案例。

展示前脱敏。保留 case ID 便于授权人员回查原始数据，不复制真实秘密和内部地址。

## 修复优先级

建议分级：

| 级别 | 判断 |
|---|---|
| P0 | 安全、隐私、数据破坏、生产越权或核心合规风险 |
| P1 | 核心任务失败、高频严重错误或明确版本回归 |
| P2 | 非核心失败、可绕过问题或中等体验影响 |
| P3 | 低频低影响、可读性或探索性问题 |

排序时综合影响、频率、严重度、证据可信度、修复成本和可回归验证性。根因未确认时优先收集证据，不直接实施大范围修复。

每项建议包含：

1. 目标层；
2. 数据证据；
3. 归因状态；
4. 修复或验证动作；
5. 预期收益；
6. 风险与依赖；
7. 对应回归用例和验收阈值。

## 负责人汇报模板

执行摘要优先回答：

1. 本轮测了什么、样本是否足够；
2. 总体结果和最重要变化；
3. 是否达到业务门槛；
4. 最大风险和受影响场景；
5. 最优先行动及验证方式。

使用示例措辞：

- “实验版本通过率比对照高 3.2 个百分点，但置信区间跨过 0，当前只能视为方向性改善。”
- “P0 总体未退化，但工具参数错误新增 4 例，集中于日期单位转换，建议阻断上线并做配对回归。”
- “Judge 与人工总体一致率较高，但高严重度样本一致性不足；最终安全结论仍需人工复核。”

避免：

- 只报百分比不报样本数；
- 把平均提升掩盖为所有维度提升；
- 将相关性描述为原因；
- 用“不显著”证明完全相同；
- 在正文展示未脱敏的失败内容；
- 不说明缺失、排除、覆盖空白和版本漂移。
